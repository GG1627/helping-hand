# Bundled interface fonts

DM Sans Regular, Medium, SemiBold, and Bold are bundled for first-open offline
use with the existing `google_fonts` theme. They are the exact static files
referenced by `google_fonts` 6.3.3, downloaded from its Google Fonts URLs with
SHA-256 and byte-length checks. `DMSans-OFL.txt` is the license from the
[Google Fonts DM Sans directory](https://github.com/google/fonts/tree/main/ofl/dmsans).
These font files are unmodified.

Fraunces remains the existing bundled wordmark font with its original license.
